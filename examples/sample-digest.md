#1 · ggerganov/llama.cpp · ⭐ 62.3k total (+4,200 this week)
🟨 Language: C++

**What it is:** Runs large language models locally on consumer hardware with minimal setup.

**Core features:**
- Supports Llama, Mistral, Gemma, Phi, and dozens of other model architectures
- Quantization down to 2-bit for running 7B models on 4GB RAM
- No Python required — pure C++ with optional Python bindings

**Who it's for:** Developers and researchers who want to run LLMs offline without a GPU cluster or cloud API budget.

**Use cases:**
- Build a private local chatbot that runs entirely on a MacBook Air
- Prototype LLM-powered features without incurring API costs during development

🔗 https://github.com/ggerganov/llama.cpp

#3 · microsoft/TypeChat · ⭐ 8.1k total (+1,650 this week)
🟨 Language: TypeScript

**What it is:** Replaces brittle prompt engineering with TypeScript types to extract structured data from LLMs.

**Core features:**
- Define your output schema in TypeScript — TypeChat handles prompt construction and validation
- Automatically retries with error feedback when the LLM returns invalid output
- Works with OpenAI, Azure OpenAI, and local models

**Who it's for:** TypeScript developers building LLM-powered features who want reliable structured outputs without hand-crafting JSON prompts.

**Use cases:**
- Parse natural language product search queries into a typed filter object
- Extract structured meeting notes from a transcript without writing a parser

🔗 https://github.com/microsoft/TypeChat
