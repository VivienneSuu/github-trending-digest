# Translation Rules — English to Chinese

## Style

Translate into fluent, natural Simplified Chinese (简体中文). Write how a technical
person in China would actually say it — not formal academic Chinese, not rigid
literal translation. Match the concise, direct energy of the English original.

## Specific Field Rules

**Repo names and owner/repo slugs:** Never translate. Keep as-is (e.g. `langchain-ai/langchain`).

**Star counts and numbers:** Translate format to Chinese convention:
- "+1,200 this week" → "+1,200 本周新增"
- "14.2k total" → "14.2k 总星标"

**"What it is":** Translate the meaning, not word-for-word. Lead with action verb in Chinese.
Example: "Runs a local LLM with one command" → "一条命令在本地运行大型语言模型"

**"Core features" bullets:** Keep as bullet points. Translate each cleanly.
Technical terms with no good Chinese equivalent (e.g. "LLM", "RAG", "API", "CI/CD") — keep in English.

**"Who it's for":** Use natural Chinese role descriptions.
- "Backend engineers" → "后端工程师"
- "ML researchers" → "机器学习研究人员"
- "Indie hackers" → "独立开发者"
- "Data scientists" → "数据科学家"

**"Use cases":** Translate the scenario. Keep concise — Chinese prose is naturally shorter.

**Links and URLs:** Never translate. Keep exactly as-is.

**Emoji:** Keep all emoji as-is.

**Section headers like "What it is", "Core features":** Translate these:
- "What it is" → "简介"
- "Core features" → "核心功能"
- "Who it's for" → "适合人群"
- "Use cases" → "使用场景"

## Header/Footer

Translate the digest header:
- "GitHub Trending Digest" → "GitHub 热门项目周报" (weekly) or "GitHub 热门项目日报" (daily)
- "These are the repositories gaining the most stars on GitHub right now." → "以下是当前在 GitHub 上获得最多星标增长的项目。"

Footer:
- "Data from github.com/trending" → "数据来源：github.com/trending"
- "To change categories, frequency, or language — just ask." → "如需更改分类、频率或语言，直接告诉我即可。"
